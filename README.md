# PSIKOLOGI EMPATI - Platform Asesmen Kepribadian, Gaya Belajar & Minat Karier

Platform evaluasi dan asesmen psikologi interaktif untuk masyarakat umum, profesional, mahasiswa, dan tim kerja di Indonesia berbasis MBTI (40 butir soal), Gaya Belajar Sensori (VAK), Pemetaan Minat Karier (Holland RIASEC), dan Analisis Sinergi Partner & Tim.

## 🚀 Fitur Unggulan
- **Tes Kepribadian MBTI Kontekstual Umum (40 Soal)** dengan skala Likert 5-poin interaktif dan hotkey keyboard [1-5].
- **Laporan Resmi Siap Cetak (PDF)** lengkap dengan Kop Surat PSIKOLOGI EMPATI, Identitas Peserta, dan Tanda Tangan Verifikasi.
- **Rekomendasi Bidang Karier & Pengembangan (Teknologi & Sains, Bisnis/Sosial/Humaniora, Kreatif & Terapan)** beserta strategi produktivitas efektif.
- **Tes Gaya Belajar VAK (Visual, Auditori, Kinestetik)** (12 soal).
- **Tes Minat Karier Holland RIASEC** (18 soal).
- **Kamus Ensiklopedia 16 Tipe Kepribadian** dengan filter dan pencarian.
- **Kalkulator Kecocokan Partner Kerja, Tim & Relasi** untuk kolaborasi harmonis.
- **Riwayat Asesmen Lokal (Offline Ready)** tersimpan di peramban tanpa memerlukan server backend database rumit.

## 💻 Cara Menjalankan di Laptop Lokal
1. Pastikan telah menginstal [Node.js](https://nodejs.org).
2. Jalankan perintah:
   ```bash
   npm install
   npm run dev
   ```
3. Akses via browser di: `http://localhost:3000`

Untuk pengguna Windows, cukup klik dua kali pada file `jalankan_aplikasi.bat`.

Panduan lengkap bagi pembeli tertera pada file `PANDUAN_PEMBELI.md`.
